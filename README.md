# Portfolio

Live site for [AreyanR](https://github.com/AreyanR) — Vite + React + TypeScript.

- **Live:** https://AreyanR.github.io/Portfolio
- **Local:** `npm run dev` → http://localhost:3001/

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Local preview (port 3001) |
| `npm run build` | Production build |
| `npm run deploy` | Build and publish to GitHub Pages (`gh-pages`) |
